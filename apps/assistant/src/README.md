# Assistant Module

## Purpose

The Assistant module provides a reusable AI Discovery Assistant for the website.

The module should eventually be extractable into a standalone package.

## Principles

- Consultant-first
- Modular
- Feature-oriented
- Framework agnostic where possible
- Reusable
- White-label ready

## Planned Features

- Chat Widget
- Conversation State
- API Client
- RAG Responses
- Source Citations
- Lead Capture
- Analytics

## Folder Responsibilities

| Folder | Responsibility |
| --- | --- |
| components | UI |
| config | Configuration |
| hooks | React hooks |
| services | API communication |
| state | Client state |
| types | Shared types |
| utils | Utilities |

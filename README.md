# LLM Engineer Project

A minimal FastAPI-based backend for building AI-powered applications.

This project is the foundation for developing a **secure, production-ready LLM system** with features like:

- Chat endpoints
- Retrieval-Augmented Generation (RAG)
- Role-based access control
- Observability and evaluation

# Start the server:

```bash
source venv/bin/activate
uvicorn main:app --reload
```
